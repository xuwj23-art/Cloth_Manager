# 阶段 02 · 商品建档（仓库端核心）

> 状态：✅ 已完成并通过自我检查 + 真实数据库端到端  
> 日期：2026-06-08  
> 范围：后端图片上传 + 移动端建档/列表界面

---

## 1. 目标

把「仓库端建档」跑通：拍照 → 选颜色/尺码批量生成 SKU → 录入进价/售价/库存 → 保存（自动生成 QR 条码）。

---

## 2. 关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 图片存储（开发期） | 后端本地磁盘 `apps/server/uploads/` + 静态服务 `/uploads/*` | 本地即可端到端，无需先接云存储 |
| 图片存储（生产） | 预留切换对象存储（OSS/COS/七牛/R2） | 见 `uploads.constants.ts` 注释 |
| 上传方式 | `multipart/form-data`，`FileInterceptor` + multer 磁盘存储 | NestJS 标准做法 |
| 图片地址 | 后端存「相对路径」，前端用 `imageUrl()` 拼 Host | 解耦 Host，便于环境切换 |
| 批量 SKU | 共享包 `expandSkuMatrix(colors × sizes)` | 杂款上新提速，前后端一致 |
| 金额单位 | 一律「分」（整数） | 避免浮点误差；界面输入元，提交转分 |

## 4. 接口

| 方法 | 路径 | 鉴权 | 说明 |
|------|------|------|------|
| POST | `/api/v1/uploads` | 是 | 上传图片，返回 `{ url: "/uploads/xxx.png" }` |
| POST | `/api/v1/products` | 是 | 建档（含批量 SKU），返回含 skus 的商品 |
| GET | `/api/v1/products` | 是 | 当前门店商品列表 |
| 静态 | `/uploads/<file>` | 否 | 访问已上传图片 |
