# 阶段 05A：蓝牙标签打印（驰腾 CTPL / X1）

> 目标：在不上架的前提下，让安卓安装版 App 直连「驰腾 X1 热转印蓝牙标签机」一键打印吊牌二维码。
> 现状：**代码已完成**，等打印机到货 + 打出开发版 APK 后做真机联调。

## 1. 方案要点

- 厂商 SDK 是 **原生 Android jar**（`ctaiotCtpl1.1.8.jar`），无法在 Expo Go 运行。
- 做成 **本地 Expo 原生模块** `apps/mobile/modules/ct-printer`，用 `requireOptionalNativeModule` 引入：
  - **Expo Go**：模块为 `null`，自动降级到「PDF / 系统打印」，日常测试不受影响。
  - **开发版/正式版 APK**：模块可用，出现「蓝牙打印」按钮。
- 二维码由**打印机原生绘制**（`drawQRCode`），比截图清晰、扫码识别率更高。
- 坐标用 **mm** 在 JS 端排版，原生侧按 **DPI** 换算成点(dot)，203/300dpi 通用。

## 3. 原生 API（CtPrinterModule.kt 暴露给 JS）

| 方法 | 说明 |
|---|---|
| `getBondedDevices()` | 系统已配对（经典蓝牙）设备列表 |
| `connect(mac, port)` | 连接，port="SPP"(默认)/"BLE"；Promise resolve 连接码(257=SPP) |
| `isConnected()` | 是否已连接 |
| `disconnect()` | 断开 |
| `queryStatus()` | 查询 DPI/纸张/碳带/间隙等，结果走 `onData` 事件 |
| `printLabels(job)` | 逐张 `clean→setSize→drawQRCode→drawText→print→execute` |

连接结果码：`256` BLE 成功、`257` SPP 成功、`258` USB 成功；其余为失败（见 SDK 手册附录）。

## 4. 标签排版（60×40 默认）

左侧二维码（内容=该 SKU 唯一条码），右侧三行：品名 / 颜色·尺码 / 价格（价格放大 2 倍）。
坐标见 `labelLayout.ts`，真机到货后按实际效果微调（改 JS 即可，不必重编原生）。
