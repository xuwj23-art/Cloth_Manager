# 打印机到货自检清单（驰腾 X1）

打印机一到货，按此清单走一遍即可完成蓝牙打印联调。

## 一、先出一个开发版 APK（Expo Go 测不了蓝牙）

> 需要一个免费 Expo 账号。没有就先 `npx expo register`，或登录已有账号。

```bash
cd apps/mobile
npm i -g eas-cli            # 首次
eas login                  # 登录 Expo 账号
eas init                   # 绑定项目（生成 projectId）
eas build -p android --profile development   # 云端打 APK
```

构建完成后 EAS 会给一个下载链接 / 二维码，手机扫码装 APK。
（若你电脑装了 Android Studio，也可 `npx expo run:android` 本地出包，不用云构建。）

## 二、配对打印机

1. 给打印机装好 **60×40 铜版纸**，开机。
2. 手机「系统设置 → 蓝牙」里**搜索并配对**打印机（名称类似 `CT-X1-xxxx`）。
3. 打开 App，授予蓝牙权限。

## 三、App 内联调

1. 进入任意商品 → 「打印吊牌二维码」→ 标签尺寸选 **60×40**。
2. 底部「选择设备」→ 选中打印机 → 显示「🟢 已连接」。
3. 设置某规格份数=1 → 「蓝牙打印」。

## 四、检查打印效果（逐项核对）

- [ ] 能正常出纸、不卡纸（间隙纸自动定位）
- [ ] 二维码清晰，**用收银扫码能识别**（最关键）
- [ ] 品名 / 颜色尺码 / 价格 三行位置合适，无超框
- [ ] 多份/多规格连续打印正常

## 五、常见微调（只改 JS，不用重编原生）

| 现象 | 改哪里（`src/printer/labelLayout.ts`） |
|---|---|
| 二维码太大/太小 | `qrCell`（默认 5，范围约 3~8） |
| 文字和二维码重叠 | 文本 `xMm` 起点（默认按宽度 46%） |
| 文字偏上/偏下 | 各行 `yMm` |
| 价格不够大 | 价格行 `scale`（默认 2） |
| 打印偏淡/偏浓 | 需在原生加 `setPrintDensity`（0~15），告诉我即可 |

## 六、需要你反馈给我的（如有问题）

- 打印出来拍张照
- App 里「连接失败」的错误码（弹窗会显示，如 `代码=518`）
- 是否需要把**店名**也印到标签上
