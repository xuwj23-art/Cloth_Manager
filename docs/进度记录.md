## 收银体验优化（真机反馈后迭代，2026-06-09）
- 问题：扫码持续对准同一二维码会每 1.2s 自动累加一件，不直观、易误加。
- 改进：扫中后**暂停继续识别**并弹出确认卡（商品图/规格/价格/库存 + 数量步进器，默认 1），用户确认后才加入；取消/确认后恢复扫码。
- 反馈：扫中成功震动、未知码错误震动（`expo-haptics`）；未找到条码用独立提示卡。
- 防超卖：确认卡按"库存 − 购物车已有"限制可加数量，达上限禁止加入。
- 共享：新增 `addToCartQty` 纯函数（按数量累加并封顶库存）+ 3 项单测（cart 共 10 测）。

## 已知问题（待办）

- **蓝牙打印首次连接闪退（自恢复）**：新装 App 后，进打印页「选择设备 → 点设备连接」，**第一次会闪退，第二次正常**。
  - 根因：厂商 CTPL SDK 为避免启动崩溃被延迟到「首次 connect() 时才 `ensureInit()`」（见 `modules/ct-printer/.../CtPrinterModule.kt`），导致首次「初始化 + 立即连接」竞态崩溃；初始化完成后第二次即正常。
  - 影响：不碰商品/库存/销售数据，功能可用，仅首次体验受影响。
  - 建议修法：把初始化提前——新增原生 `prepare()`/在 `getBondedDevices()` 内 `ensureInit()`，于「打开设备列表」时就初始化，连接时不再与初始化竞态。属原生改动，需 prebuild + 重打包 + 真机实测。
  - 状态：2026-06-11 与用户确认**暂缓**（自恢复、不影响数据）。

  - 月份用**下拉选择**（最近 12 个月，弹窗单选），不再横排 12 个月。
  - 每日明细**只列出有销售额的日期**；点某天进入**当日流水**列表（`GET /sales/by-day`），可再点开单据详情。
- **扫码框限制**：去掉之前「坐标超出视图就放行」的错误兜底（expo-camera v17 已把坐标映射到视图坐标系）；改为「拿到坐标且不在绿框内则忽略」，并加**自愈保护**：连续 25 次被框过滤（疑似该机型不返回坐标）则自动放开，避免完全扫不出。
- **标签纵向（旋转 90°）**：物理标签是 60×40（60mm 边先出，横版进纸），软件无法旋转纸张，故新增**「打印方向：纵向/横向」**开关：
  - 横向=内容正排（二维码居中靠上 + SKU + 价格）。
  - 纵向=在 60×40 画布上把内容旋转 90°（二维码靠左占满 40mm 高、尽量大；SKU/价格 `drawText` 用 `Rotate.Degree90`）。打印后把标签转 90° 即为「二维码在上 / SKU / 价格在下」的纵向标签（40 宽 × 60 高）。
  - **原生改动**（`CtPrinterModule.kt` 支持每段文本 `rotate` 角度 + `CtTextOp.rotate`）→ **必须重打包 + 重装 APK**，OTA 不含原生。
  - ⚠️ 待真机校准：纵向文本若上下颠倒/错位，切换 `labelLayout.ts` 的 `PORTRAIT_TEXT_ROTATE`(90↔270) 或微调 `codeXMm/priceXMm/centerY`。
- 自检：server/mobile `tsc` 通过、lint 无错。

### 04F 实测修正（2026-06-13）
- **标签纵向**（据实物照片校准 `buildPortrait`）：① 文本居中公式 `(H+L)/2`→`(H-L)/2`（原导致贴边/SKU 被切）；② 二维码与文本上下顺序修正为「二维码在上 / SKU / 价格在下」并整组沿 X 居中；③ 二维码加大（cell 10）。纯 JS，可走 OTA。
- **扫码框范围限制：回退**。expo-camera 在该机型返回的坐标不可靠（去兜底仍拦不住）且每帧计算拖慢识别，按用户「要么解决要么回退」选择回退为原生扫码，绿框仅作视觉提示（移除 `scanCenter/insideFrame/camSize/onLayout`）。
- **销售历史返回逻辑**：把销售记录的内部导航状态（tab/月份/选中日）提升到 `App.tsx`，进出单据详情不再丢层级；硬件返回/手势在「历史→当日明细」先回到月列表，再回首页（不再直接退出或跳回今日）。
- **标签纵向微调**：二维码水平右移与文字居中对齐（`PORTRAIT_QR_Y_ADJUST_MM`）、整组上移（`PORTRAIT_GROUP_X_ADJUST_MM`），按实物逐步校准。
- **SKU 条码改纯数字**：`generateBarcode`→10 位纯数字（查库去重 + 冲突重试），手动输入栏改数字键盘，便于人工录入。仅影响新建商品，旧条码（前缀+十六进制）不变仍可扫；**服务端改动需 git pull + 重新编译**。
- **蓝牙首次连接闪退修复**：`getBondedDevices` 打开设备列表时即 `ensureInit()`，消除「首次 connect 同帧初始化」竞态。**原生改动，需重打包重装 APK**。
