# UI 设计参考与设计语言（面向中老年用户）

> 本文件是移动端界面重构（第 4 波 C3/C4）的设计输入。基于 Mobbin 真实 App 界面分析 + 产品约束（PRD §2 中老年用户、§3 设计原则）提炼。
> **权威性**：参考性，指导界面重构的视觉/交互方向。
> 日期：2026-08-04

---

## 一、用户约束（必须满足）

| 维度 | 约束 | 设计含义 |
|------|------|----------|
| **年龄** | 中老年为主 | 字号大、对比强、点击区大、操作步数少 |
| **智能机熟练度** | 不高 | 符合直觉的交互（系统标准模式）、无明显手势、无隐藏入口 |
| **场景** | 店内收银（有时手忙脚乱） | 关键动作（扫码/结算）大按钮、防误触确认 |
| **视力** | 可能退化 | 最小正文字号 ≥16sp，金额数字超大 |
| **认知** | 软件零基础 | 功能入口"图标+文字"双编码，不靠图标猜 |

## 二、核心场景的 UI 参考与提炼

### 2.1 首页功能入口 → 参考 Grab 四宫格
**[Grab 首页](https://mobbin.com/screens/5913ee73-d562-4dbf-aaeb-15dc9d123e7f)**

**提炼的设计**：
- **大图标 + 文字双编码**（图标辅助识别、文字确认含义）——中老年友好的黄金标准
- **四宫格大入口**（数量少、面积大），不用密集小图标
- 图标语义必须直白（扫码枪=收银、衣服=商品、图表=报表、蓝牙=打印）

**本项目应用**：
- HomeScreen 四个入口：**扫码收银** / **商品列表** / **销售报表**（owner）/ **标签打印**（owner）
- 店员视图只显示：扫码收银 / 商品列表（两个大入口）
- 顶部保留"今日营业额"大数字卡（owner 可见，店员不可见——PRD §6）

### 2.2 今日营业额卡 + 销售流水 → 参考 Monzo 账户页
**[Monzo 账户页](https://mobbin.com/screens/2eb613ac-522c-41cd-bcbe-b289273a7e8d)**

**提炼的设计**：
- **顶部超大数字卡**（今日营业额，¥XXX.XX，字号 36-40sp），一眼能看懂
- **按日期分组的流水列表**（Today / 昨天 / 日期），每条：商品摘要 + 金额 + 时间
- 关键金额用强调色（如品牌主色），其余黑/灰
- 极简留白，信息层级靠字号而非分割线

**本项目应用**：
- HomeScreen 顶部"今日营业额"大数字卡（点按进报表）
- SalesScreen 流水按日期分组（与 Monzo 同构）
- 报表页"今日/本周/本月"三个大卡片，数字超大、单位小（¥大、.XX 小）

### 2.3 商品列表 → 参考 Etsy 商品卡片
**[Etsy 商品列表](https://mobbin.com/screens/736b0210-423e-4ad9-a6c7-80a31d1d5a1c)**

**提炼的设计**：
- **大封面图 + 品名 + 价格 + 库存**，图占卡片视觉主体
- 卡片信息：图（大）→ 品名（中字号）→ 价格（强调）→ 库存（辅助色）
- 列表单列或双列，不密集（中老年需更大点击区）

**本项目应用**：
- ProductsScreen 卡片：封面图 + 品名 + SKU 数 + 总库存 + 最低售价
- "在售/已售罄"切换用顶部分段控件（大段，不靠小图标）
- 下拉刷新保留（手势直觉）

### 2.4 购物车与结算确认 → 参考 Starbucks 订单确认页
**[Starbucks 订单确认](https://mobbin.com/screens/d2980f68-0b6f-49a4-9aa4-d9a9172fa059)**

**提炼的设计**：
- **商品行 = 图 + 名 + 价 + 数量步进器**（步进器大按钮 - / +）
- **底部固定大按钮**（"结算 ¥XXX"），始终可见
- 卡片清单 + 底部确认的标准模式

**本项目应用**：
- CashierScreen 购物车：每行图+名+规格+价+数量步进器（-/+ 大按钮）
- 扫码确认卡（扫中弹出）：大商品图 + 规格 + 价 + 库存 + 数量步进器（默认1）+ "加入"大按钮
- 底部固定结算栏：件数 + 总价 + "结算"大按钮
- 结算前确认弹窗：件数 + 总价 + 确认/取消（防误触，PRD §3.4）

### 2.5 商品建档表单 → 参考 Vestiaire 上架页
**[Vestiaire 上架表单](https://mobbin.com/screens/ac476f10-604e-4a00-af48-1df08cc1effe)**

**提炼的设计**：
- **顶部大照片区**（带相机图标，点击拍照/选图）——照片是建档视觉焦点
- **下方垂直字段列表**，每行带清晰标签 + 大输入框/选择器
- 颜色/尺码用 chips（多选），点击即选，再点取消
- 必填项明确（售价+库存），可选项折叠（品名/颜色/尺码在"详细设置"）

**本项目应用**：
- CreateProductScreen：顶部拍照区 → 售价+库存（必填大字段）→ "详细设置"折叠区（品名/颜色尺码 chips/品类）
- chips 要大（点击区 ≥44pt），选中态高对比（填充色 + 勾）

## 三、设计语言提炼（重构时的统一规范）

### 3.1 视觉基调：简洁精致
- **背景**：浅灰 #F5F5F7（非纯白，护眼）+ 卡片纯白 + 微阴影
- **主色**：单一品牌色（建议沉稳深色，如墨绿 #1A5638 或 深蓝 #1E3A5F，显高级不花哨）
- **文字**：主文字 #1A1A1A，辅助文字 #6B7280，金额用主色
- **留白**：充足，信息层级靠字号与留白，少用分割线

### 3.2 字号（中老年友好）
| 元素 | 字号 | 说明 |
|------|------|------|
| 金额大数字（营业额/总价） | 36-40sp | 一眼可见 |
| 标题/品名 | 18-20sp | 清晰 |
| 正文/字段标签 | 16-17sp | **不低于 16sp**（中老年最小可读） |
| 辅助信息（时间/库存） | 14sp | 仅用于次要信息 |

### 3.3 点击区
- **最小 48×48dp**（Android 无障碍标准），步进器/按钮建议 56×56dp
- 卡片整张可点，不嵌套小按钮

### 3.4 动画（润滑切换，不花哨）
- **页面切换**：横向滑动 200-250ms ease-out（标准导航动效）
- **卡片入场**：列表项错位淡入（stagger 30ms），不夸张
- **状态反馈**：扫码成功震动 + 淡入确认卡（150ms）；按钮按下轻微缩放（0.97）
- **避免**：复杂转场、3D 翻转、长时间加载动画（中老年会以为卡住）
- **库**：React Native Reanimated（性能好、流畅）

### 3.5 功能入口识别度（不花哨）
- **图标 + 文字双编码**（PRD 约束：不靠图标猜）
- 图标用**填充式**（filled，比线性 outline 更易识别）
- 文字标签简短直白（"扫码收银"而非"POS"、"商品列表"而非"Inventory"）
- 入口数量少（≤4），面积大

### 3.6 表格与统计（一眼懂、好操作）
- **优先大数字卡 + 简单柱状图**，不用复杂表格
- 柱状图：粗柱、带数值标签、最多 7 根（今日/本周每日）
- 利润率用进度条或大百分比数字，不用饼图（中老年难读饼图）
- 月份选择用**下拉选择器**（不用横排 12 个月，已在 04F 实现）
- 每日明细只列有销售额的日期，点按展开当日流水

## 四、动画与交互库选型（第 4 波技术决策）

| 需求 | 选型 | 理由 |
|------|------|------|
| 页面导航 + 切换动画 | `@react-navigation/native-stack` | 系统标准转场，中老年熟悉，不花哨（C3） |
| 列表/卡片入场动画 | `React Native Reanimated 3` + `FlashList` | 性能好、流畅、支持 stagger（C4） |
| 状态反馈（震动/缩放） | `expo-haptics` + Reanimated | 已在用 expo-haptics，扩展 |
| 弹窗/确认卡 | React Navigation Modal 或自建 BottomSheet | 大按钮、半透明遮罩、点击区大 |

> Reanimated 与 React Navigation 都是 RN 生态主流，社区维护活跃，符合"易维护易升级"。

## 五、不要做的事（避免中老年困惑）

| 反模式 | 原因 |
|--------|------|
| 隐藏式抽屉菜单（汉堡菜单） | 中老年不会点三横线 |
| 纯图标底部 Tab（无文字） | 不认图标含义 |
| 手势返回（边缘滑动）作为唯一返回 | 必须有可见的返回箭头 |
| 长按触发功能 | 零基础用户不会尝试长按 |
| 复杂图表（饼图/雷达图） | 难读，用大数字 + 简单柱状图替代 |
| 过快动画（<150ms）或过慢（>400ms） | 快了看不见、慢了以为卡住 |
| 低对比文字（灰底灰字） | 看不清 |
| 多层级折叠菜单 | 找不到入口 |
