# 账号权限说明（老板 / 员工）

> 面向使用者的说明文档。系统目前只有两种角色：**老板（店主）** 和 **员工（店员）**。
> 一个门店有且只有一个注册老板，员工账号由老板在 App 内创建。

## 一、两种角色怎么来的

| 角色 | 如何获得 |
| --- | --- |
| 老板（owner） | 在登录页用「注册门店」创建。注册时填门店名 + 手机号 + 密码，系统自动开通门店并把你设为老板。 |
| 员工（staff） | 不能自行注册。由老板在 App 里「员工管理」中创建（设置姓名 + 手机号 + 初始密码），员工用该手机号密码登录。 |

## 二、权限对照表

✅ 可用　❌ 不可用

| 功能 | 老板 | 员工 | 说明 |
| --- | :---: | :---: | --- |
| 登录 / 退出 | ✅ | ✅ | |
| 扫码收银、开单结账 | ✅ | ✅ | 收银是员工的核心工作 |
| 查看商品列表 | ✅ | ✅ | 收银时需要看到商品 |
| 扫码 / 手动条码匹配商品 | ✅ | ✅ | 收银兜底 |
| 商品建档（新增商品） | ✅ | ❌ | 含拍照、定价、库存 |
| 上传 / 拍摄商品图片 | ✅ | ❌ | 仅老板，控制图片来源与存储 |
| 编辑商品（改名 / 改价 / 盘点库存） | ✅ | ❌ | |
| 商品下架 / 恢复在售 | ✅ | ❌ | |
| 打印二维码吊牌 | ✅ | ❌ | 与建档配套 |
| 查看销售流水（明细列表） | ✅ | ❌ | 经营数据，员工看不到 |
| 查看销售报表（今日/本周/本月汇总） | ✅ | ❌ | |
| 查看单据详情 | ✅ | ❌ | |
| 员工管理（查看成员 / 新增员工） | ✅ | ❌ | |

## 三、设计原则（为什么这么分）

1. **员工只管"卖"**：员工能扫码、改成交价（议价）、结账，但看不到进价、利润、营业额等经营数据，避免敏感信息外泄。
2. **老板掌握"账与货"**：建档、定价、库存盘点、上下架、查看所有流水与报表，都集中在老板账号。
3. **收银动作双方都能做**：保证柜台正常运转，老板临时顶班也能直接收银。

## 四、常见疑问

- **员工能改价吗？**
  能。收银时可对单行「改价」用于讨价还价/优惠，但这只影响本单成交价，不会改动商品档案里的标准售价。
- **员工能看到一天卖了多少钱吗？**
  不能。销售流水、报表、单据详情都仅限老板查看。
- **忘记密码怎么办？**
  目前没有自助找回。员工密码可由老板重新创建账号或后续在「员工管理」中重置（如已支持）；老板密码需在后端数据库处理。
- **一个手机号能注册几个门店？**
  一个手机号只能注册一次（注册时若手机号已存在会提示"已注册"）。

> 注：后端通过 JWT + 角色校验强制以上权限，App 界面也会按角色隐藏老板专属入口；即使绕过界面直接调用接口，服务器也会拒绝越权操作。
