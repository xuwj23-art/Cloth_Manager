# 服务器部署指南（阿里云轻量 · Ubuntu 24.04 · Docker）

面向 0 基础。全程在**阿里云控制台的网页终端**里复制粘贴命令即可，不用装任何 SSH 软件。

- 服务器：阿里云轻量应用服务器，Ubuntu 24.04，2核2G
- 部署内容：PostgreSQL 数据库 + NestJS 后端，监听 `3000` 端口
- 部署后访问地址：`http://你的公网IP:3000/api/v1`
- 代码仓库：`https://github.com/xuwj23-art/Cloth_Manager`

---

## 第 1 步：连接服务器（网页终端）

1. 登录阿里云 → 轻量应用服务器控制台 → 找到你的实例。
2. 点 **「远程连接」 / 「Workbench 远程连接」** → 用户名 `root` + 你设置的密码 → 进入黑色命令行界面。

> 之后所有命令都在这个网页终端里粘贴运行。

---

## 第 2 步：安装 Docker（用 Ubuntu 自带源 + 阿里云镜像，国内最稳）

> 不要用 `get.docker.com` 脚本——国内访问常被重置（`Connection reset by peer`）。
> 直接用 Ubuntu 软件源（阿里云镜像）安装，最稳。

整段粘贴运行（`-o DPkg::Lock::Timeout=600` 会自动等待新机开机后的后台更新锁释放）：

```bash
apt-get -o DPkg::Lock::Timeout=600 update
apt-get -o DPkg::Lock::Timeout=600 install -y docker.io docker-compose-v2
systemctl enable docker --now

# 验证：分别打印出版本号即成功
docker version
docker compose version
```

### 配置镜像加速（拉取 node/postgres 镜像更快）

```bash
mkdir -p /etc/docker
cat > /etc/docker/daemon.json <<'EOF'
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://docker.1ms.run"
  ]
}
EOF
systemctl restart docker
```

---

## 第 3 步：拉取代码

```bash
# 安装 git（若已存在会跳过）
apt-get update && apt-get install -y git

# 浅克隆（只取最新版本，速度快）
cd /opt
git clone --depth 1 https://github.com/xuwj23-art/Cloth_Manager.git
cd Cloth_Manager
```

> 如果 `git clone` 卡住或很慢（国内连 GitHub 偶尔不稳），告诉我，我给你换成镜像加速地址。

---

## 第 4 步：填写密钥配置 `.env`

在仓库根目录生成 `.env`（数据库密码和 JWT 密钥都自动随机生成）：

```bash
cd /opt/Cloth_Manager
cat > .env <<EOF
DB_PASSWORD=$(openssl rand -hex 16)
JWT_SECRET=$(openssl rand -hex 32)
EOF

# 看一眼（请把这两行抄下来保存好）
cat .env
```

---

## 第 5 步：启动后端

```bash
cd /opt/Cloth_Manager
docker compose -f docker-compose.prod.yml up -d --build
```

- 第一次会构建镜像 + 装依赖，约 3~8 分钟，请耐心等。
- 完成后查看状态：

```bash
docker compose -f docker-compose.prod.yml ps
docker compose -f docker-compose.prod.yml logs -f server
```

看到日志里出现 `服务已启动: http://localhost:3000/api/v1` 就成功了（按 `Ctrl+C` 退出日志查看，**不会**停掉服务）。

---

## 第 6 步：放行 3000 端口（关键！）

阿里云轻量默认只开放了少量端口，必须手动放行 `3000`：

1. 阿里云控制台 → 你的实例 → **「防火墙」/「安全组」** → 添加规则。
2. 应用类型：自定义；协议：**TCP**；端口范围：**3000**；授权对象：`0.0.0.0/0`。
3. 保存。

> 服务器系统自带的 `ufw` 防火墙在阿里云镜像里通常是关闭的，一般无需额外操作。若开启了：`ufw allow 3000/tcp`。

---

## 第 7 步：验证

在**服务器终端**里：

```bash
curl http://localhost:3000/api/v1/health
```

返回类似 `{"status":"ok","db":"ok",...}` 即正常。

然后在**你自己的电脑/手机浏览器**打开（把 IP 换成你的公网 IP）：

```
http://你的公网IP:3000/api/v1/health
```

能看到同样的 JSON，说明外网可访问，后端部署完成 ✅

---

## 日常运维命令（备查）

```bash
cd /opt/Cloth_Manager

# 查看运行状态
docker compose -f docker-compose.prod.yml ps

# 查看后端日志
docker compose -f docker-compose.prod.yml logs -f server

# 重启后端
docker compose -f docker-compose.prod.yml restart server

# 停止全部
docker compose -f docker-compose.prod.yml down

# 启动全部
docker compose -f docker-compose.prod.yml up -d
```

---

## 以后如何更新后端（改了代码之后）

1. 本地：`git push`（推之前记得开代理）。
2. 服务器终端：

```bash
cd /opt/Cloth_Manager
git pull
docker compose -f docker-compose.prod.yml up -d --build
```

数据库数据和已上传图片都保存在 Docker 数据卷里，更新不会丢失。
